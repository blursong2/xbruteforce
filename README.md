# xbruteforce
!! EDUCATIONAL PURPOSE ONLY !!

x (formaly twitter) account bruteforce tool via x api

트위터 핸들 입력 후 시도할 비밀번호 자릿수 입력하면 됨

# 주의사항
이 레포는 교육 목적에 있음

애초에 3자릿수도 80만개 조합이 나오는데 트위터의 최소 비밀번호 갯수는 10자 이상임

현재 어떤 방식으로 비동기 http 요청 여러개를 전송하여

어떤 방식으로 429 요청을 우회할 수 있고 <- 사실 이건 아래 트러블슈팅항목에나와잇지만 애매하긴함 알아서 포크열어서보완하셈

그렇게 발견된 취약점들을 통해서

어떤 방식으로 우리가 운영중인 사이트들을 보호해야하는지에 대한 교육 목적에 있음

# 트러블슈팅
429에 대한 보완을 워커 수로 무식한 방법으로 해결함

따라서 우회 매커니즘을 저걸로 의존중임, 만약 배드리퀘스트에 걸렸다면 워커 수를 줄이는 방식으로 시도해보자

코드 103줄 아래에 있는 `num_workers = 20`의 수를 줄여보자
